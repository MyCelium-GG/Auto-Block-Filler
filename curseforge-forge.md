# AutoBlockRefiller (Forge)

Empty hotbar slots refill automatically while you build.

When placing blocks empties your hotbar slot or offhand and more of the same
block are in your inventory, a fresh stack slides in a moment later. Silent,
server side, no keybinds.

- Only refills slots that are actually empty
- Main inventory first, never touches armour or offhand stock
- Config: `enabled` (default true), `searchHotbar` (default false)

Requires **Mycel**. Needs Forge 66.0.9+, Minecraft 26.3, Java 25.
