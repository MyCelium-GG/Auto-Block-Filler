Operators click a value to change it. /autoblockrefiller toggle: Any player turns refilling off or on, just for themselves. /autoblockrefiller set <setting> <value>: Operators change a setting, with tab completion. /autoblockrefiller reset <setting>|all: Operators put settings back to their defaults." width="100%">
