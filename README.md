Silent, server side, a couple of ticks later." width="100%">

![Behavior](https://raw.githubusercontent.com/MyCelium-GG/Auto-Block-Filler/95abe575e3ed/docs/img/banners/behavior.svg)

<img src="https://raw.githubusercontent.com/MyCelium-GG/Auto-Block-Filler/95abe575e3ed/docs/img/banners/behavior-box.svg" alt="Triggers on right-click placement with a block item; verifies 2 ticks later. Refills only when the used slot is actually empty (failed placements and manual swaps are respected, never overwritten). Sources: main inventory first; other hotbar slots only with searchHotbar. Armour, offhand and crafting slots are never taken from. Works per hand: selected hotbar slot and offhand are both covered." width="100%">

![Anonymous stats](https://raw.githubusercontent.com/MyCelium-GG/Auto-Block-Filler/95abe575e3ed/docs/img/banners/anonymous-stats.svg)

<img src="https://raw.githubusercontent.com/MyCelium-GG/Auto-Block-Filler/95abe575e3ed/docs/img/banners/anonymous-stats-box.svg" alt="AutoBlockRefiller sends anonymous stats (how often slots get refilled, with which blocks, and errors in its own code) to its FastStats project through Mycel. It follows Mycel's choice exactly: the one-time screen in your own game, shareStats / shareErrors in config/mycel.json on servers." width="100%">

A config screen is available from the mod list on Forge and NeoForge." width="100%">
